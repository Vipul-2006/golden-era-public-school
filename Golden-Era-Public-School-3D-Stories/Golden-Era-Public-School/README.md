# The Golden Era Public School — Multi-page website

## Open in VS Code
1. Extract the ZIP.
2. Open the extracted `Golden-Era-Public-School` folder in VS Code.
3. Install the **Live Server** extension.
4. Open `index.html`, right-click and choose **Open with Live Server**.

## Pages
- `index.html` — Home
- `pages/about.html` — About
- `pages/academics.html` — Academics
- `pages/facilities.html` — Facilities
- `pages/gallery.html` — Gallery
- `pages/admissions.html` — Admission enquiry form (demo front-end only)
- `pages/contact.html` — Contact details
